CAPABILITIES

Visibility and control, in one place.

Operate Xray without changing routes every time a network probe is temporarily inconclusive.

◇

Quorum health checks

Independent targets via VPN and WAN. Ambiguous results preserve the current route.

↔

Controlled failover

A scored Xray hot pool with deliberate switching and safety constraints.

≡

Subscription management

Supported VLESS subscription sources in one interface.

▣

Web management

Dashboards, settings, diagnostics and server-enforced permissions.

✓

Signed updates

Verifiable releases and guarded update trials with documented rollback limits.

⌘

CLI & API

Headless daemon, local CLI operations and authenticated APIs.

UNDER THE HOOD

Separated responsibilities.

Go components keep privileged network control separate from the web user interface.
